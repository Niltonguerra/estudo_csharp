**Plano de estudos — C# Backend (básico ao avançado)**

**Objetivo 1 — Console app com lógica básica**  
App de console simulando cadastro em memória. Foco em sintaxe, tipos, coleções, classes, métodos e interfaces.

**Objetivo 2 — API REST CRUD básica**  
API com ASP.NET Core com endpoints completos. Sem banco ainda, dados em memória.

**Objetivo 3 — Persistência com Entity Framework Core**  
Conectar a API a PostgreSQL, usar migrations, repositórios e relacionamentos básicos.

**Objetivo 4 — Segurança com JWT**  
Autenticação e autorização com JWT, roles e middleware de segurança.

**Objetivo 5 — Testes**  
Testes unitários com xUnit, mocks com Moq e testes de integração com WebApplicationFactory.

**Objetivo 6 — Refatorar para Clean Architecture**  
Reorganizar em camadas — Domain, Application, Infrastructure, Presentation. Aplicar SOLID na prática.

**Objetivo 7 — Sistema distribuído**  
Dois serviços se comunicando via RabbitMQ ou Kafka. Aplicar padrão Saga e resiliência com Polly (equivalente ao Resilience4j do Java).

**Objetivo 8 — Performance e boas práticas avançadas**  
Cache com Redis, paginação eficiente, queries otimizadas, logging estruturado com Serilog.

**Objetivo 9 — Projeto final publicado**  
Docker + Kubernetes ou deploy em VPS. CI/CD básico com GitHub Actions.
